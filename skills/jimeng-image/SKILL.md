# 即梦AI 文生图技能

## 配置

在使用前，你需要在 `memory/jimeng-key.txt` 中配置你的即梦API Key。

或者直接告诉我你的 Key，我帮你配置。

## API Key 申请

1. 访问 [即梦AI开放平台](https://jimeng.jianying.com)
2. 注册并登录
3. 前往开发者中心获取 API Key

## 使用方式

告诉我你想生成的图片内容，我会帮你生成。

支持的图片比例：1:1, 16:9, 9:16, 3:4, 4:3 等

## 提示词模板

生成海报：
```
[主题描述]，高端风格，[配色描述]，[装饰元素]，[排版方式]，高质量，精致细节
```

生成人像：
```
[人物描述]，[风格]，[背景]，[光线]，[画质]
```
