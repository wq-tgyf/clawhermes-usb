ClawHermes-USB 便携版

────────────────────────────
Windows
────────────────────────────
1. 若存在 ClawHermes-Control-Electrobun.exe，双击它。
2. 若没有 Electrobun 启动器，双击 ClawHermes-Control.exe。
3. 在控制面板里填写 API 地址、模型名、API Key。
4. 点「启动服务」，拉起共享 payload 服务。

────────────────────────────
macOS
────────────────────────────
1. 双击 Start-ClawHermes-Mac.command。
2. 若 macOS 拦截该脚本，在本目录打开终端执行：
     chmod +x Start-ClawHermes-Mac.command Stop-ClawHermes-Mac.command
     ./Start-ClawHermes-Mac.command
3. 若已打包 ClawHermes-Control-Mac.app，启动器会自动打开它。
4. 若未打包，启动器会在浏览器里打开本地门户（Portal）。

发布说明
────────────────────────────
- Windows 与 macOS 共享 core、adapters、apps、portal、config、data、skills。
- 平台相关的启动器与运行时放在发布根目录，或 runtimes/ 下。
- release-manifest.json 记录已复制的 payload、入口点与警告信息。
